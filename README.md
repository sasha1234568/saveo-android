## Установка

1. Скачайте `Saveo.apk` на устройство с Android 7.0 или новее.
2. Откройте скачанный файл.
3. Если Android запросит разрешение, разрешите установку приложений из этого источника, например браузера.
4. Нажмите «Установить».

Для обновления скачайте новый APK и установите его поверх предыдущей версии. Удалять приложение перед обновлением не требуется.

## Проверка файла

В каждом релизе опубликован файл `SHA256SUMS` с контрольной суммой APK.

Этот репозиторий предназначен для распространения готовых сборок приложения.
